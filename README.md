# Music Playlist Management

A C++ project for managing a music playlist using a Doubly Linked List.

## Problem Statement

To develop a menu-driven C++ program to manage a music playlist using a Doubly Linked List, allowing users to add, delete, search, and display songs, as well as navigate between songs in forward and backward directions.

## Data Structure Used

**Doubly Linked List**

Each song is stored as a node containing:
- Song name
- Pointer to the previous song
- Pointer to the next song

## Operations

1. Add Song
2. Delete Song
3. Search Song
4. Display Playlist
5. Next Song
6. Previous Song
7. Exit

## Concepts Used

- C++
- Structures
- Pointers
- Dynamic Memory Allocation
- Doubly Linked List
- Insertion
- Deletion
- Searching
- Traversal

## Project Files

- `main.cpp` – C++ source code
- `program-output.pdf` – Program output showing the operations

## Conclusion

The project demonstrates how a Doubly Linked List can be used to manage a music playlist and allows navigation in both forward and backward directions.
